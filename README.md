# AC Office

Büro-App für AC Security Consulting & Training – läuft komplett im Browser (Chrome/Edge, Android ab Chrome 132).

**Es liegen hier keine Daten.** Kunden, Rechnungen, Lehrgänge usw. bleiben ausschließlich im Datenordner auf dem jeweiligen Gerät, den die App über die File System Access API öffnet. Diese Seite liefert nur das Programm aus.
